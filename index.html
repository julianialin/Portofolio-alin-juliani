A little bit
about myself.

Halo! Saya Alin Juliani, siswi jurusan Rekayasa Perangkat Lunak (RPL) di SMKN 1 Kawali. Saya mulai mengenal dunia pemrograman dari kegiatan belajar di sekolah, terutama tentang bagaimana sebuah website dibuat dan bekerja.

Selama belajar RPL, saya berkesempatan mencoba beberapa teknologi seperti HTML, CSS, PHP, MySQL, dan Laravel. Awalnya mungkin banyak hal yang terasa baru, tetapi dari situ saya belajar untuk lebih teliti, mencari tahu saat menemukan kesulitan, dan memahami prosesnya sedikit demi sedikit.

Saat ini saya juga sedang menjalani pengalaman PKL. Buat saya, pengalaman tersebut menjadi kesempatan untuk mengenal suasana kerja secara langsung, belajar menyelesaikan tugas, dan menerapkan ilmu yang sebelumnya saya dapatkan di sekolah.

Saya belum merasa menguasai semuanya. Masih banyak hal yang ingin saya pelajari, dan saya ingin terus mengembangkan kemampuan melalui pengalaman serta proyek-proyek berikutnya.
